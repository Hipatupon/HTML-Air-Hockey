# HTML Air Hockey 🏒

A lightweight, browser-based implementation of the classic arcade Air Hockey game built using standard web technologies (HTML, CSS, and JavaScript). Enjoy fast-paced puck action directly inside your web browser without any additional plugins or installations.

## 🚀 Features

- **Browser-Ready:** Play instantly within any modern web browser.
- **Responsive Controls:** Smooth mouse or touch controls to maneuver your paddle.
- **Arcade Physics:** Dynamic collision detection and physics for realistic puck bouncing and sliding.
- **Lightweight & Fast:** Built natively with vanilla web tech for optimal performance and zero dependencies.

## 🕹️ How to Play

1. **Clone or Download** this repository to your local machine:
   ```bash
   git clone https://github.com/Hipatupon/HTML-Air-Hockey.git
   ```
2. **Open** the project folder.
3. Double-click or open the `index.html` file in your preferred web browser (Chrome, Firefox, Edge, Safari, etc.).
4. Use your **mouse** or **touchscreen** to control your mallet, defend your goal, and strike the puck into your opponent's net!

## 🛠️ Built With

- **HTML5 Canvas:** For high-performance 2D rendering and graphics.
- **CSS3:** For layout styling and interface presentation.
- **JavaScript (ES6):** For game loop management, user input handling, and collision physics mechanics.
